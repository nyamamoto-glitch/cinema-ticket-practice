# AIにテストケースを生成させるためのプロンプト

[演習トップに戻る](../index.html)

人が設計したテストとAIが生成したテストを、同じ採点ツールで比較するためのプロンプトです。
生成AI（ChatGPT、Claude、Gemini など）に、下のプロンプトと仕様書の全文を渡してください。

## 比較のしかた

1. 下の「プロンプト」をコピーし、末尾に [仕様書](spec.html) の本文をすべて貼り付けて、AIに送ります。
2. AIが出力したCSVを [採点ツール](../checker/index.html) に貼り付けて採点します。
3. 人が設計したテストも同じ形式で採点し、結果を比べます。

比較の公平さを保つために、次の条件をそろえることをおすすめします。

- **テストの件数**：人とAIで上限をそろえる（例：どちらも20件まで）
- **与える情報**：AIにも人にも、仕様書だけを渡す（演習版の画面やソースコードは渡さない）
- **生成の回数**：AIの生成は1回の結果を使う（何度もやり直して良い結果を選ばない）

## プロンプト

```text
あなたはソフトウェアテストのエンジニアです。
以下の仕様書を読み、料金計算機能のテストケースを20件設計してください。

# 出力形式
次の列を持つCSVだけを出力してください（説明文は不要です）。
id,age,date,time,member,3d,count,expected

- id：T01 から始まる連番
- age：年齢（そのまま入力する値）
- date：鑑賞日（YYYY-MM-DD）
- time：上映開始時刻（HH:MM）
- member：none / regular / premium のいずれか
- 3d：yes / no のいずれか
- count：枚数（そのまま入力する値）
- expected：仕様書から導いた期待する合計金額（数字のみ）。入力エラーになるべき場合は ERROR

# 注意
- 期待値は必ず仕様書の記述から計算してください。
- 曜日が関係する場合は、その日付の実際の曜日を確認してください。

# 仕様書
（ここに仕様書の本文を貼り付けてください）
```

## 発展：条件を変えて比べる

- テストの件数を10件・40件に変えると、検出数はどう変わるか。
- 「テスト技法（境界値分析、デシジョンテーブルなど）を使って設計してください」と指示を加えると、結果は変わるか。
- 仕様書の一部（例：2-2の「最も安い料金を採用」）を削ると、AIの期待値はどう変わるか。
